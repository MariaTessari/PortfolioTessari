## 🌐 Portfolio Tessari
Este projeto foi desenvolvido para apresentar alguns trabalhos e projetos realizados na escola.

---

## 📌 Sobre o projeto

Este portfólio foi desenvolvido como parte das minhas atividades escolares ao longo dos trimestres, com o objetivo de reunir e apresentar os projetos que desenvolvi durante esse período.
Além de funcionar como uma vitrine dos meus trabalhos, o projeto também foi utilizado como forma de prática e aprimoramento das minhas habilidades em desenvolvimento web, principalmente na construção de interfaces, organização de código e criação de layouts responsivos.

Meu Portfólio Contém: 
- Meus projetos e trabalhos realizados  
- Informações sobre mim  
- Formas de contato
